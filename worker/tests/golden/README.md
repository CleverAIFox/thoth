# 골든셋

**여기에 실제 학습 사이트의 문항을 넣지 않는다.** 이 저장소는 원문을
재배포하지 않는다는 것이 설계의 전제다(PLAN §4). 골든셋 파일은 커밋되고
공개되므로, 원문을 넣으면 선행 저장소를 폐기한 이유가 그대로 재현된다.

대신 **모양만 닮은 창작 지문**을 쓴다. 실제 워크로드와 길이 분포 · 용어 밀도 ·
문장 구조가 같아야 한다. 짧은 샘플로 잰 수치는 실사용을 대표하지 않는다
(DECISIONS §6).

## 맞춰야 할 모양

2026-09-13 에 대상 사이트의 채점 후 화면에서 잰 값이다. **원문은 재지 않고
길이 통계만 뽑았다.** 케이스를 고칠 때 이 표에서 벗어나지 않는지 본다.

| 구분 | 개수 | 글자(중앙) | 단어(평균) | 물음표 |
|---|---|---|---|---|
| 문제 | 1 | 420 | 71 | 있음 |
| 보기 | 4 | 165 (142~172) | 24 | 없음 |
| 해설 | 4 | 424 (407~485) | 51 | 없음 |

★ **표본이 문항 하나다.** 이 값에 중앙값을 ±10% 로 맞추려 들지 않는다.
실측 자체가 흔들리므로(해설 407~485) 정밀하게 맞추는 것은 표본 하나에
과적합하는 짓이다. **같은 자릿수이고 분포 폭이 비슷하면 충분하다.**

★ 길이를 닮아야 하는 이유는 하나뿐이다 — 짧은 샘플로 재면 처리율을 잘못
본다(DECISIONS §6). 그 목적에 필요한 정밀도는 자릿수 수준이지 소수점이
아니다. 문항이 늘면 실측을 다시 떠서 이 표를 갱신한다.

★ **한 문항이 9개 유닛이다.** 케이스를 낱개로 늘어놓지 않고 문항 단위로
묶는다. 그래야 배치 번역의 용어 일관성을 잴 수 있다.

★ **현재 5문항 45유닛 13,954자다.** q1 Kinesis 보존 기간 · q2 Glue 크롤러 ·
q3 Redshift 분산 · q4 Spark 파티션 스큐 · q5 DynamoDB 핫 파티션. 주제를 겹치지
않게 두는 이유는 용어집이 한 도메인에 쏠리면 나머지가 검증되지 않기 때문이다.

★ **위 규약을 `worker/tests/test_bench_checks.py` 가 지킨다.** 유닛 수 · 구성 ·
id 유일성 · 물음표 위치 · 길이 분포 · `keep` 토큰이 원문에 실재하는지를 본다.
케이스는 손으로 쓰고 문항이 늘 때마다 사람이 규약을 기억해야 하는데, 그 기억은
세션이 바뀌면 사라진다(DECISIONS §9).

★ **`keep` 에 원문에 없는 토큰을 적지 않는다.** 번역문에도 없을 것이므로 반드시
위반이 되고, 검사가 모델이 아니라 케이스의 오타를 잡는다.

★ **영한 번역의 정상 길이 비율은 0.44~0.53 이다**(2026-09-13 실측 18유닛).
한국어가 영어보다 짧으므로 1을 넘는 값은 정상이 아니다. 임계값을 실측 없이
정하면 검사가 성립하지 않는다(DECISIONS §19).

★ 물음표는 문제에만 있다. 환각(모델이 번역 뒤에 답을 이어 붙임)이 나오는
자리가 거기다.

## 무엇을 재는가

번역의 '정확도' 를 재지 않는다. 측정할 수 없는 목표는 세우지 않는다
(MASTER §8). 검증 가능한 불변식만 본다.

| 불변식 | 근거 |
|---|---|
| `keep` 의 토큰이 영어 그대로 남는다 | MASTER §7-2 규칙 1 |
| 등재 용어의 한국어 표기를 쓴다 | MASTER §8 |
| 원문이 물음표로 끝나면 번역도 그렇다 | PLAN §2-2 #14 |
| 출력 길이가 `ratio_min` ~ `ratio_max` 안에 있다 | 덧붙임 · 누락 |
| 합니다체로 끝난다 | MASTER §7-2 규칙 3 |

## 실행

```bash
rm -f worker/.cache/translations.json   # 캐시를 비운다
bash tools/run_worker.sh &              # 재려는 ENGINE 으로
python3 tools/bench_golden.py           # 점수표. 웜업은 기본으로 돈다
```

★ 속도를 볼 때는 캐시와 모델 상태를 둘 다 비운 것으로 본다. 자세한 것은
`docs/bench/README.md` 에 있다(DECISIONS §6 · §27).
