# thoth — 실행 계획

> **앞으로 할 일만 담는 문서다.** 끝난 것은 결과를 `MASTER.md` 로, 왜 그렇게 됐는지는
> `DECISIONS.md` 로 옮기고 **여기서는 행을 지운다.** 포인터도 남기지 않는다.
>
> | 문서 | 시제 | 담는 것 |
> |---|---|---|
> | **`docs/PLAN.md`** | **미래** | **남은 일 · 미결정 · 범위 밖 · 위험 (이 문서)** |
> | `docs/MASTER.md` | 현재 | 규약 · 계약 · 운영 · 비용 |
> | `docs/DECISIONS.md` | 과거 | 왜 그렇게 됐나 (append-only) |
>
> 서술 규약은 MASTER §0 이고 `tools/check_docs.py` 가 강제한다. 이 문서에만 걸리는 것은
> 아래 넷이다.

### 이 문서의 규약

| 규칙 | 강제자 |
|---|---|
| 남은 일은 **§1 표 하나**에만 산다. 다른 절에 번호 행을 두지 않는다 | `check_plan` 「표 행이 §1 밖에 있다」 |
| §1 제목이 행 수를 든다 — `## 1. 남은 일 — N행` | `check_plan` 「제목은 N행인데」 |
| **행 번호는 영구 식별자다.** 결번이 정상이고 지운 번호는 다시 쓰지 않는다. 당기지 않고 빈자리를 채우지 않는다 | `check_plan` 「오름차순 · 겹친다」 |
| 상태는 📄 🟡 ⏳ ⚠ 넷뿐이다. 닫힘 표시(`✅` · `⬛`)는 어휘 밖이다 — 닫힌 행은 지운다 | `check_plan` 「어휘 밖」 · 「닫힘 표시」 |

| 표기 | 뜻 |
|---|---|
| 📄 | 할 일이 정해졌으나 코드 · 실측으로 확인 안 됐다 |
| 🟡 | 미결정. 판단이 필요하다 |
| ⏳ | 대기 — **여기서 못 푼다.** 막고 있는 것이 행 안에 있다 |
| ⚠ | 전제가 틀리기 쉽다. 다른 표기와 함께 쓴다 |

★ **⏳ 는 필요 없다는 뜻이 아니다.** 설계와 막힌 이유가 행에 그대로 있으므로 조건이 오면
처음부터 판단하지 않고 이어받는다. 그래서 지우지 않는다(파이어레인 PLAN §0-2).

★ **번호를 당기지 않는 이유**는 DECISIONS 가 append-only 라서다. 당기면 DECISIONS 의 옛
인용이 **조용히 다른 행을 가리킨다** — 죽은 참조보다 나쁘다(파이어레인 DECISIONS §205).
이 저장소는 처음부터 당기지 않았다(DECISIONS §18).

## 0. 다음 한 수

**이 저장소를 껍데기로 닫는다**(DECISIONS §94). 끼우는 자리는 섰다 — `ENGINE=http`
(MASTER §7-4). 남은 행을 닫거나 조건 대기로 내리는 것이 다음 수이고, 그 뒤 이 저장소에서
할 일은 #59 하나다.

★ 이 절은 새 세션이 문맥 없이 시작할 때 읽는 자리다. 한 수가 정해지면 갱신한다.

★ **#59 의 절차는 MASTER §7-4 에 있다.** 적합성 검사 → `terraform.tfvars` 의 `engine` ·
`http_url` · `http_model` · `http_token` → 손 `plan` → 태그. 되돌리는 것도 한 줄이다.

★ **#25 의 설계.** 경로를 새로 만들지 않는다 — 확장 → 워커 → stdout JSON 한 줄 → 같은
구독 필터 · 같은 Firehose. 판별자 `k` 를 하나 더 둔다. 첫 판단은 필터를 넓히는가 테이블을
하나 더 두는가, 둘째는 실패의 정의다 — `collect` 가 0 인 순회는 정적인 페이지에서
정상이고(`idle` 이 센다) 어댑터가 `match` 했는데 0 인 것과 예외가 난 것을 가른다. 관측
행은 확장 안에 섰고 픽스처가 스스로 채점한다(MASTER §3-0 · §11-5).

★ **#26 은 자동 반영하지 않는다.** 후보를 뽑고 사람이 승인해서 등재한다(DECISIONS §8).

★ **#56 은 픽스처가 드러냈다.** `standard` 는 자기 몫을 모으고 나머지를 `genericCollect`
에 넘기는데(DECISIONS §11) `udemy` 는 넘기지 않는다. 강의 소개 · 시작 화면 · 결과 요약이
빠진다. 판단할 것은 범위다 — 위임하면 Udemy 의 UI 문구까지 번역 대상이 된다.

★ **#57 이 웹스토어의 진짜 전건이다.** 공개 확장에 공용 토큰을 넣으면 누구나 꺼낸다
(MASTER §12). 비용은 배포자가 낸다. 로그인은 붙이지 않는다 — 설치 단위 한도와 월 전체
상한 두 겹이면 개인 규모 무료 도구의 남용은 막힌다. 판단할 것은 셋이다 — 키를 무엇에
묶는가, 발급을 무엇으로 막는가, 한도를 몇으로 두는가.

★ **#37 이 범용성 그 자체다.** Udemy 밖은 `generic.js` 폴백 하나에 얹혀 있다. **#38 은
UX 가 아니라 결함이다** — `번역 중` 이름표는 증상을 가린 것이다. **#39 는 쌍 로그와 한
쌍이다** — 원문 · 번역 · 사용자 판정이 함께 쌓여야 학습 신호가 된다.

## 2. 지금 무엇이 막혀 있는가

**막는 것이 없다.** 배포까지 섰고 실사이트에서 돈다.

**비용은 제약이 아니다.** 45유닛 한 판이 $0.00293 이고 월 상한을 다 태워도 $0.59 다
(MASTER §7-0-2).

**로컬 추론이 문항 하나에 81초라는 사실은 그대로다.** GTX 1660 Ti 의 처리율이 천장이라
코드로 줄일 수 없다(DECISIONS §6 · §36). 제품의 속도는 호스팅이 정하고(문항당 5.2초)
`local` 은 오프라인 개발과 비교 기준선으로 남는다. `local` 기준선은 `stale` 이다 — 고유명사
절 지시를 바꾼 뒤(DECISIONS §66) `bedrock` 만 다시 쟀다.

## 4. 범위 밖

**하지 않기로 한 것**이다. 나중에 "왜 안 했지" 를 다시 묻지 않기 위해 적는다.

| 항목 | 사유 |
|---|---|
| 스크래핑 · 봇 감지 우회 | 저작권 · ToS. 선행 저장소의 폐기 사유다 |
| 번역 원문의 저장소 배포 | 위와 같다 |
| 다음 문제 선번역 | 화면에 없는 것을 가져오면 스크래핑이다 |
| ECS · Fargate · ALB | 요청이 간헐적이라 상시 기동 고정비가 맞지 않는다 |
| GPU 인스턴스 자체 호스팅 | 시간당 과금. 유휴에도 나간다 |
| 사용자별 API 키(BYOK) | 번역 비용을 사용자에게 떠넘기는 구조다 |
| 사이트별 사전 조사 | 제네릭 계층이 어댑터 없이 동작한다 |
| 런타임 LLM 의 DOM 추론 | 느리고 비싸고 비결정적이다 |
| AWS Custom Terminology | AWS 전용이라 엔진을 바꾸면 이식되지 않는다 |
| 후처리의 형태소 분석기 교체 | 모델을 갈아끼운다. 규칙 후처리는 돌아가는 만큼에서 멈춘다(DECISIONS §108) |
| `git apply --3way` | 실측에서 판정을 개선하지 못했다. `--index` 를 함의해 스테이징까지 바꾼다(DECISIONS §61) |

★ **늙은 행 둘을 지웠다.** "승인자 게이트 — 단독 작업이라 두지 않는다" 는 2026-09-16 에
게이트를 걸면서(DECISIONS §98) 거짓이 됐고, "문서 강제자 테스트 — 유지 비용이 값을
넘는다" 는 강제자 2판이 서면서(DECISIONS §111) 거짓이 됐다. 범위 밖 표도 늙는다.
