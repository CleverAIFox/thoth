# 기준선

다른 엔진을 고를 때 대조군으로 쓰는 수치다. 같은 골든셋을 같은 러너에
돌려 여기 값과 비교한다(PLAN §3 #35).

## 왜 필요한가

절대값만 보면 좋아졌는지 나빠졌는지 알 수 없다. 2026-09-13 에 배치 번역을
넣자 위반이 6 → 8 로 늘었는데, 앞 숫자가 없었다면 배치를 되돌렸을 것이다.
종류별로 쪼개 보니 환각 3건이 사라지고 문체 2건이 는 것이었고, 프롬프트
순서를 고쳐 5 가 되었다(DECISIONS §20).

## 재는 법

```bash
rm -f worker/.cache/translations.json   # 캐시를 비운다
bash tools/run_worker.sh &              # 재려는 ENGINE 으로
python3 tools/bench_golden.py --json out.json
```

★ **캐시를 비우지 않으면 속도가 거짓이 된다.** 캐시 히트 실행은 번역을
하지 않으므로 0.2초가 나오고, 그 값을 기준선에 넣으면 26,660자/초 같은
숫자가 남는다(DECISIONS §6 의 재발).

★ 골든셋 문항이 늘면 `golden.units` 도 바뀐다. 문항 수가 다른 두 실행을
비교하지 않는다.
